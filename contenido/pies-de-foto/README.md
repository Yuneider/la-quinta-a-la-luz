# Pies de foto

Aquí están los textos que salen bajo cada foto del carrusel (y en la vista ampliada). Hay un archivo por carpeta de `contenido/`, con el mismo nombre:

| Archivo | Imágenes de |
|---|---|
| `01-jardin.txt` … `14-alberca.txt` | `contenido/01-jardin/imagenes/` … |
| `alrededores.txt` | `contenido/alrededores/imagenes/` |
| `uv/01-tributo.txt` … | `contenido/uv/01-tributo/imagenes/` … |

## Cómo se escribe

Una línea por imagen: el nombre del archivo, una barra `|` y el pie.

```
01_COMEDOR_1.jpg | El comedor, con la mesa servida como para un banquete de época.
```

- No importa la extensión ni las mayúsculas: `COMEDOR_1.jpg` también sirve para `comedor_1.jpeg`.
- Las líneas que empiezan por `#` son notas y no salen en la vista.
- Si una imagen no tiene pie, el texto alternativo sale de su nombre de archivo (sin tildes).
- Si renombras una imagen, cambia también su línea aquí. La sincronización avisa cuando un pie apunta a una imagen que no existe.

Los pies actuales son un **borrador**: revisa autores, fechas y nombres antes de publicarlos como definitivos, y anota los créditos de cada imagen.
